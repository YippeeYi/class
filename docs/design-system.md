# 编日史视觉系统

## 设计定位

编日史是供成员回看、检索和补充内容的班级内容站。界面采用克制的现代编辑型布局，优先保证内容关系、扫描效率和阅读舒适度，不把首页处理成营销页、沉浸式展览或复古档案装置。

## 设计令牌

- 画布和表面：项目既有 `--theme-surface` 与 `--theme-surface-strong` 生成暖中性色。
- 文字：沿用 `--text-main`、`--text-strong` 与 `--text-subtle`，保证背景切换后仍由原有主题机制控制。
- 强调色：只使用现有 `--theme-accent-strong` 表示当前选择、键盘焦点、链接与重要记录。
- 分隔与圆角：使用低对比度单线分隔，标准圆角为 8-10px。阴影只用于浮层、登录卡和必须浮起的容器。
- 字体：沿用项目本地 Google Sans Flex 与系统中文回退。标题不靠过大字号或花哨字形建立层级。

## 内容规则

- 首页是紧凑导览。核心记录占更大阅读权重，人物与名言作为辅助入口，其他功能入口以低干扰文本块排列。
- 记录页使用受控正文宽度和连续分隔，重要记录才获得唯一强调边界。
- 人物、名言、搜索和统计优先使用可扫读的列表、表格和分组，不堆叠重复大卡片。
- 资料、地图、答题、背景与致谢沿用同一套表面、分隔、控制和焦点规范。

## 交互与适配

悬停只改变边界和背景，不位移、不翻转、不添加持续动画。所有可交互元素拥有可见焦点。760px 以下首页和工具面板收为单列，表格保留横向滚动，不压缩内容语义。`prefers-reduced-motion` 下关闭过渡和动画。
