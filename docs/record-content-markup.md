# 记录正文标记语法

记录正文与可选 `annotation` 字段共用同一个 AST 解析器与渲染组件。引用等双参数标记使用 `[[type:参数1|参数2]]`；媒体和公式使用单参数标记 `[[type:内容]]`。annotation 缺失、null 或空白时不显示入口。

| 功能 | 推荐写法 |
|---|---|
| 人物 | `[[person:人物ID|显示文字]]` |
| 额外记录人 | `[[author:人物ID|显示文字]]` |
| 名言 | `[[quote:名言ID|显示文字]]` |
| 记录跳转 | `[[record:文件名|显示文字]]` |
| 资料跳转 | `[[material:资料ID|显示文字]]` |
| 注解 | `[[anno:注解内容|被注释文字]]` |
| 插图 | `[[illu:example.png]]` |
| 视频 | `[[video:example.mp4]]` |
| 内联公式 / 化学式 | `[[latex:x^2+y^2]]`、`[[latex:\ce{H2O}]]` |
| 删除线 | `[[del:文字]]` |
| 下划线 | `[[under:文字]]` |
| 标红 | `[[red:文字]]` |
| 黑幕 | `[[hide:文字]]` |
| 表格 | `[[table:行数x列数|单元格1|单元格2|...]]` |
| 居中 | `[[center:文字]]` |
| 右对齐 | `[[right:文字]]` |

参数内容可以嵌套其他统一标记。例如：

```text
[[anno:注解中包含 [[person:zhx|小张]]|被注释文字]]
[[under:公式 [[latex:\\frac{a}{b}]]]]
```

`[[person:...]]` 表示事件参与者；`[[author:...]]` 表示正文中补充的额外记录人。额外记录人与记录 JSON 的 `author` 字段共同计入记录事件，但不会仅因 `author` 标记而计入参与事件。

## 转义

标记参数中的特殊字符使用反斜杠转义：

```text
\|  普通竖线
\[  普通左方括号
\]  普通右方括号
\\  普通反斜杠
```

JSON 字符串还需要转义反斜杠。例如正文中的 `A|B` 可写为：

```json
{
    "content": "[[anno:A\\|B|标签]]"
}
```

## 参数限制

- 人物和名言 ID 只能包含英文字母、数字、下划线和连字符。
- 记录文件名只能包含英文字母、数字、下划线和连字符，可带 `.json`。
- 普通插图参数只填写文件名；渲染器会补全固定目录 `data/attachments/`。迁移脚本会把 hidden 数据中的同类标记自动改写为内部专用的 `hidden/文件名`，并映射到 `hidden/data/attachments/`。除这个受控前缀外，文件名不能包含路径分隔符，并须使用 `png`、`jpg`、`jpeg`、`gif`、`webp` 或 `svg` 扩展名。
- 插图参数只接受文件名，不接受完整目录路径。
- 表格行数限制为 1～30，列数限制为 1～12；缺少的单元格按空内容处理，多余单元格忽略。单元格可以嵌套其他统一标记。
- 未知类型、缺少参数或未闭合的标记会安全地作为普通文本显示。

## 排版与浮层保证

- 不含插图的正文表格不会建立横向滚动区，也不会依靠 `overflow: hidden` 裁切。少列表格按内容收缩；内容较重的列获得更大比例；高列数和窄容器会压缩列宽并降低单元格横向 padding。含插图的表格在窄屏无法同时容纳文字和媒体列时，仅表格区域可横向滚动。中文按正常断行规则换行，连续英文、数字和 URL 在必要时可安全断开。
- 数学与化学表达式统一使用内联 `[[latex:...]]`。分式写为 `\frac{a}{b}`，上下标写为 `^{...}`、`_{...}`，反应箭头可写为 `\rightarrow` 或 `\rightleftharpoons`；普通正文、编号和注脚标号保持原样。
- 注释使用 Portal 中的 shadcn HoverCard，短内容按内容收缩，长内容限制在正文可读宽度并自动换行；鼠标悬停、键盘聚焦/Enter 与移动端触控均可打开。鼠标打开时只在首次出现前记录一次 `clientX`，让注释框水平中心尽量对齐指针；视口碰撞修正完成后，本次显示期间锁定位置，关闭后才允许下一次重新取点。退出阶段继续保留本次 `alignOffset`，让 Base UI 的淡出/缩放动画在当前实际位置结束，不会先回到触发元素中心。键盘和触控入口回退到触发元素中心。注释正文采用“引用可交互”模式：人物、作者、记录、资料和名言继续渲染为可点击链接。注解字段本身使用完整正文渲染，支持媒体和公式。
- 插图在标记位置显示按原比例缩放的预览图，可见图片高度为当前正文的两行行高；极宽图片在窄容器内优先完整显示且不溢出。发布流程生成公开、隐藏内容分离的受保护媒体尺寸索引，记录数据加载后统一预取并缓存尺寸；尺寸尚未知晓时不会先显示错误比例的图片占位框。已知尺寸后在固定比例的区域中央显示圆环，预览加载成功后移除；点击后使用统一大图查看器加载原图。视频始终独占正文一行，使用浏览器原生控制条，接近视口时才获取签名地址，只预载 metadata。含插图的表格会为媒体列保留可读宽度，窄屏空间不足时仅表格区域可横向滚动。
- LaTeX 使用 KaTeX 内联渲染，支持 `\ce{}` 化学式。JSON 文件中的反斜杠需按 JSON 规则写为 `\\`；例如 `"[[latex:\\frac{a}{b}]]"`。公式源内容不再次解析网站标记，未闭合的 `]]` 不允许直接出现。渲染始终使用 `trust: false`。

## 迁移和检查

在发布前先运行本地内容审计，再查看只读线上差异；正式发布会保留现有标记语法并只上传实际引用的资源。

```bash
npm run content:audit
npm run content:plan
node scripts/test-record-markup.mjs
npm run test:layout
```
