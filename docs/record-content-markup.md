# 记录正文标记语法

记录正文统一使用 `[[type:参数1|参数2]]`。旧式花括号、圆括号、感叹号、箭头、无类型人名和单字符上下标不再解析。

| 功能 | 推荐写法 |
|---|---|
| 人物 | `[[person:人物ID|显示文字]]` |
| 额外记录人 | `[[author:人物ID|显示文字]]` |
| 名言 | `[[quote:名言ID|显示文字]]` |
| 记录跳转 | `[[record:文件名|显示文字]]` |
| 分式 | `[[frac:上方文字|下方文字]]` |
| 注解 | `[[anno:注解内容|被注释文字]]` |
| 插图 | `[[illu:example.png|显示文字]]` |
| 删除线 | `[[del:文字]]` |
| 下划线 | `[[under:文字]]` |
| 标红 | `[[red:文字]]` |
| 黑幕 | `[[hide:文字]]` |
| 上标 | `[[sup:文字]]` |
| 下标 | `[[sub:文字]]` |
| 箭头上下结构 | `[[arrow:上方文字|下方文字]]` |
| 表格 | `[[table:行数x列数|单元格1|单元格2|...]]` |
| 居中 | `[[center:文字]]` |
| 右对齐 | `[[right:文字]]` |

参数内容可以嵌套其他统一标记。例如：

```text
[[anno:注解中包含 [[person:zhx|小张]]|被注释文字]]
[[frac:[[del:上方文字]]|[[under:下方文字]]]]
```

`[[person:...]]` 表示事件参与者；`[[author:...]]` 表示正文中补充的额外记录人。额外记录人与记录 JSON 的 `author` 字段共同计入记录事件，但不会仅因 `author` 标记而计入参与事件。

## 转义

标记参数中的特殊字符使用反斜杠转义：

```text
\|  普通竖线
\[  普通左方括号
\]  普通右方括号
\\  普通反斜杠
```

JSON 字符串还需要转义反斜杠。例如正文中的 `A|B` 可写为：

```json
{
    "content": "[[anno:A\\|B|标签]]"
}
```

## 参数限制

- 人物和名言 ID 只能包含英文字母、数字、下划线和连字符。
- 记录文件名只能包含英文字母、数字、下划线和连字符，可带 `.json`。
- 普通插图参数只填写文件名；渲染器会补全固定目录 `data/attachments/`。迁移脚本会把 hidden 数据中的同类标记自动改写为内部专用的 `hidden/文件名`，并映射到 `hidden/data/attachments/`。除这个受控前缀外，文件名不能包含路径分隔符，并须使用 `png`、`jpg`、`jpeg`、`gif`、`webp` 或 `svg` 扩展名。
- 插图参数只接受文件名，不接受完整目录路径。
- 表格行数限制为 1～30，列数限制为 1～12；缺少的单元格按空内容处理，多余单元格忽略。单元格可以嵌套其他统一标记。
- 未知类型、缺少参数或未闭合的标记会安全地作为普通文本显示。

## 排版与浮层保证

- 正文表格不会建立横向滚动区，也不会依靠 `overflow: hidden` 裁切。少列表格按内容收缩；内容较重的列获得更大比例；高列数和窄容器会压缩列宽并降低单元格横向 padding。中文按正常断行规则换行，连续英文、数字和 URL 在必要时可安全断开。
- 分式与方程式箭头使用 `inline-grid` 的 intrinsic track；横线宽度由上下两段最终渲染宽度中较大者决定，并向两侧略微延伸。箭头头部和相邻正文保留独立间距。
- 注释使用 Portal 中的 shadcn HoverCard，短内容按内容收缩，长内容限制在正文可读宽度并自动换行；鼠标悬停、键盘聚焦/Enter 与移动端触控均可打开。鼠标打开时只在首次出现前记录一次 `clientX`，让注释框水平中心尽量对齐指针；视口碰撞修正完成后，本次显示期间锁定位置，关闭后才允许下一次重新取点。键盘和触控入口回退到触发元素中心。注释正文采用“引用可交互”模式：人物、作者、记录、资料和名言继续渲染为与正文一致的可点击链接，嵌套注释或插图只保留可见标签，避免递归创建浮层或 Dialog。
- 插图在浮层首次出现前锁定固有尺寸和鼠标 `clientX`；首次水平中心尽量对齐该指针位置，完成视口碰撞修正后，本次打开期间不再随鼠标移动。

## 迁移和检查

在上传前使用 `npm run admin -- upload --dry-run` 进行结构与引用预检查；正式上传时脚本会保留现有标记语法并只上传实际引用的资源。

```bash
npm run admin -- upload --dry-run
node scripts/test-record-markup.mjs
npm run test:layout
```

迁移器遍历 `data` 下的全部 JSON 字符串字段。`--check` 只检查，不写文件。
